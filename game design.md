# Дизайн-документ игры

## Сюжет и герои

Группа героев состоит из воина, разведчицы и жреца. Сюжет раскрывается через сюжетные сцены с диалогами.

Игрок общается с неигровыми персонажами.

## Задания

Прохождение включает основное задание и второстепенные задания. Для работы с заданиями предусмотрен журнал заданий.

## Передвижение и исследование

Игрок управляет основным персонажем, остальные герои следуют за ним. Группа перемещается по локациям и между сценами.

Игрок исследует локации, включая подземелья, в поисках предметов и снаряжения. Для исследования предусмотрена карта.

## Развитие героев

Развитие героев основано на опыте, уровнях и характеристиках. Меню статуса содержит описание всех характеристик, опыт и уровень героя.

## Инвентарь и расходники

Инвентарь хранит расходники и ненадетое снаряжение. Для доступа к нему предусмотрено меню инвентаря.

Во время исследования игрок находит следующие расходники:

- Лечебные зелья.
- Воскрешающие зелья.
- Усилители защиты и сопротивления.
- Усилители атаки.
- Модификаторы атаки.
- Атакующие предметы.

## Снаряжение

Игрок находит снаряжение во время исследования. Для работы со снаряжением предусмотрено меню снаряжения.

### Оружие

Оружие определяет урон и специализацию героя. Доступные виды оружия ограничены классом.

| Класс | Доступное вооружение |
| --- | --- |
| Воин | Одноручные мечи, щиты, двуручные мечи |
| Разведчица | Луки, кинжалы, кистевое оружие |
| Жрец | Посохи, булавы, косы, книги |

### Броня

Броня служит источником основной защиты. Доступный тип брони ограничен классом.

| Класс | Тип брони |
| --- | --- |
| Воин | Латы |
| Разведчица | Кожаные доспехи |
| Жрец | Тканевые доспехи |

### Кольца и амулеты

- Кольца служат источником модификаторов атаки.
- Амулеты служат источником модификаторов сопротивления.

## Билды и специализации

У каждого героя свой класс. Билд формируется надетым снаряжением, которое влияет на специализацию, атаку, защиту и модификаторы атаки и сопротивления.

Специализация зависит от выбранного оружия и определяет спецприём героя.

### Воин

| Специализация | Вооружение |
| --- | --- |
| Дуэлянт | Один одноручный меч |
| Гладиатор | По одноручному мечу в каждой руке |
| Страж | Одноручный меч и щит |
| Берсерк | Двуручный меч |

### Разведчица

| Специализация | Вооружение |
| --- | --- |
| Рейнджер | Лук |
| Вор | Кинжал |
| Разбойница | Два кинжала |
| Ассасин | Кистевое оружие |

### Жрец

| Специализация | Вооружение |
| --- | --- |
| Некромант | Коса |
| Фанатик | Булава |
| Священник | Булава и священная книга |
| Колдун | Булава и оккультная книга |
| Волшебник | Посох |

## Встречи с врагами

Враги перемещаются по карте. Игрок вступает в бой, «наступив» на врага.

## Боевая система

Бой проходит в отдельной сцене между группой игрока и группой противника.

### Действия и инициатива

В бою предусмотрен список доступных действий:

- Атака.
- Спецприём.
- Использование предметов.

Боевая система включает шкалу инициативы и ожидание.

### Боевые мини-игры

- Мини-игра атаки определяет промах, попадание или критический удар.
- Мини-игра защиты определяет получение удара, блок или уворот.

### Исходы и состояния

Бой предусматривает победу над врагом и поражение. Для участников боя предусмотрено состояние нокаута.

## Сохранение, загрузка и отдых

В точках сохранения и отдыха игрок сохраняет игру, восстанавливает здоровье и ману и возрождает всех врагов.

Загрузка сохранённой игры доступна из главного меню или меню команды.

## Завершение игры

Завершение игры связано с выполнением основного задания и финалом сюжета.
