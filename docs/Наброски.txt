Что в игре будет:
Можно узнать сюжет:
Есть группа героев. Это воин, разведчица и жрец.
Есть сюжетные сцены с диалогами.

Можно общаться
Есть неигровые персонажи

Можно выполнять задания
Есть основное задание
Есть второстепенные задания
Есть журнал заданий

Можно ходить
Есть передвижение
Есть основной персонаж которым управляет игрок. Остальные идут за ним.
Есть перемещение между сценами

Можно прокачиваться
Есть опыт
Есть уровни
Есть характеристики
Есть меню статуса, где описаны все характеристики, опыт и уровень

Можно исследовать локацию в поисках предметов и снаряжения
Есть подземелья
Есть инвентарь где можно хранить расходники и не одетое снаряжение
Есть карта

Можно находить расходники
Есть лечебные зелья
Есть воскрешающие зелья
Есть уселители защиты и сопротивления
Есть усилители атаки
Есть модификаторы атаки
Есть атакующие предметы
Есть меню инвентаря

Можно находить снаряжение
Есть оружие. От него зависит урон и специализация. Но оно ограничено по классу.
Есть одноручные мечи, щиты и двуручные мечи - их носит воин
Есть луки, кинжалы и кистевое оружие - их носит разведчица
Есть посохи, булавы, косы, книги - их носит жрец
Есть броня как источник основной защиты. Она ограничена по классу
Есть латы. Их носит воин
Есть кожаные доспехи. Их носит разведчица.
Есть тканевые доспехи. Их носит жрец.
Есть кольца как источник модификаторов для атаки
Есть амулеты как источники модификаторов для сопротивления
Есть меню снаряжения

Можно строить билд
Есть классы. У каждого героя свой.
Есть надетое снаряжение которое влияет на специализацию, атаку, защиту и модификаторы атаки и сопротивления
Есть специализации, которые определяют спецприем героя в зависимости от выбранного оружия.
Есть дуэлянт - это воин вооруженный одним одноручным мечем
Есть гладиатор - это воин с одноручным мечем в каждой руке
Есть страж - это воин с одноручным мечем и щитом
Есть берсерк - это воин с двуручным мечем
Есть рейнджер - это разведчица с луком
Есть вор - это разведчица с кинжалом
Есть разбойница - это разведчица с двумя кинжалами
Есть ассасин - это разведчица кистевым оружием
Есть некромант - это жрец с косой
Есть фанатик - это жрец с булавой
Есть священик - это жрец с булавой и священной книгой
Есть колдун - это жрец с булавой и оккультной книгой
Есть волшебник - это жрец с посохом

Можно встретить врагов
Есть враги, которые ходят по карте. На них можно "наступить" чтобы вступить с ними в бой

Можно сражаться
Есть сцена битвы
Есть группа игрока
Есть группа противника
Есть список доступных действий
Есть атака
Есть спецприем
Есть использование предметов
Есть шкала инициативы
Есть ожидание
Есть миниигра для определения промаха, попадания и критического удара
Есть миниигра для определения получения удара, блока и уворота
Есть победа над врагом
Есть поражение
Есть нокаут

Можно сохранять игру и отдыхать
Есть точки для сохранения и отдыха. Тут можно сохранить игру, восстановить здоровье и ману и возродить всех врагов.
Есть возможность загрузки из главного меню или меню команды

Можно завершить игру
Есть завершение основного задания и финал сюжета.
