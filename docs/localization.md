# Локализация

Используется официальный пакет Unity Localization 1.5.13. Поддерживаются русский (`ru`) и английский (`en`). Начальный язык определяется по `Application.systemLanguage`: русский для русской системы, английский для остальных. Выбор в настройках применяется сразу и живёт только в текущем запуске игры, включая переходы между сценами. PlayerPrefs и файлы сохранений не используются.

## Где редактировать текст

Единый источник переводов — [GameText.json](../Assets/Localization/GameText.json). Каждая запись содержит уникальный `key` и варианты `ru`/`en`. Названия языков отображаются на их собственном языке: «Русский» и «English».

Например:

```json
{ "key": "dialog.door.locked", "ru": "Заперто.", "en": "Locked." }
```

Для текста с данными используются обычные позиционные параметры: `{0}`, `{1}`. Например, `party.health` содержит `ОЗ {0}/{1}` и `HP {0}/{1}`. Передавать параметры нужно в одинаковом порядке для обоих языков.

## Импорт в Unity

После установки пакета и перезагрузки скриптов GameLocalizationImport автоматически создаёт настройки, Locale ru/en и коллекцию String Tables `GameText` в `Assets/Localization/Generated`. Изменение JSON запускает обновление таблиц. Повторный импорт сохраняет существующие ключи и их числовые ID, обновляя значения; отсутствующие ранее ключи добавляются. Встроенная система Unity включает таблицы и Locale в Addressables.

Импорт также доступен через `Tools > Localization > Import Game Text`. Его нужно завершить в режиме редактирования до запуска игры или сборки. Генерированные таблицы и настройки создаются редакторскими API; вручную их не изменяем. JSON является источником переводов, поэтому редактирование значений только в окне Localization Tables будет перекрыто следующим импортом.

## Подключение к игровым объектам

- В DialogProp назначается `dialogKey`, в Door — `lockedDialogKey`.
- В Chest назначаются Found Dialog Key, Empty Dialog Key и Locked Dialog Key. Реплика находки получает {0} — локализованное имя предмета и {1} — количество. DialogService.TryShowDialog и DialogView.Show поддерживают необязательную функцию параметров, которая вызывается заново при обновлении языка/интерфейса.
- В ItemDefinition назначаются Name Key и Description (ключ описания); переводы предметов находятся в GameText.json под item.<id>.name и item.<id>.description.
- В PartyCharacterDefinition назначается `characterNameKey`, в CharacterClassDefinition — `classNameKey`.
- `PartyService.TryAddMember` принимает ключ имени в аргументе `nameKey`; `DialogService.TryShowDialog` и `DialogView.Show` принимают ключ реплики.
- В коде текст получается через `GameLocalization.Text(key, параметры)`. До завершения асинхронной загрузки таблиц возвращается пустая строка; меню и новые диалоги в это время не открываются. После загрузки и смены языка вызывается `GameLocalization.Changed`. Представления подписываются на событие при включении и отписываются при отключении.
- При отсутствии перевода используется английская запись. Если ключ отсутствует в обеих таблицах, показывается `[key]` и предупреждение в консоли.

Настройки реализованы отдельным SettingsPanelView и SettingsScreenTemplate. Общий MenuPanel отвечает за переходы между главным меню, инвентарём, статусом и настройками, а также за контекст ввода. Строка языка принимает влево/вправо только при фокусе; стрелки и курсор показаны через `:focus`. Мышь не управляет меню.

## Статус проверки

Импорт пакета, компиляция и поведение в Unity после этих изменений не проверены. Тесты, сборки и Play Mode не запускались. Для ручной проверки: дождаться установки пакета и создания таблиц, проверить начальный язык системы, переключение в обе стороны, переводы меню/статуса/предметов/запертых дверей, сохранение выбора при переходе сцены и сброс к системному языку после нового запуска.
